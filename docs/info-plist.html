Plist reference

Info.plist

The current developer-facing keys accepted by a component .foundrypack. Paths are relative to Contents/Resources.

Identity

type

Required String

component, theme, or collection. The remaining component-specific keys on this page apply when the type is component.

CFBundleIdentifier

Required String

Globally unique, stable reverse-domain identity, for example uk.co.example.callout. Changing it creates a different component.

title

Required String

Human-readable library and inspector name.

description

Optional String

Short library description.

author

Optional String

Developer, company or publisher.

version

Optional String

Human-readable component version such as 1.0 or 2.1.3.

group

Optional StringDefault: Other

Library group: Layout, Content, Media, Navigation, Forms, Interactive, or Other.

tags

Optional String array

Additional component-library search terms.

Rendering

requiresPhp

Optional BooleanDefault: false

Exports every page containing an instance of this component with an index.php filename instead of index.html. A nested child component can require PHP for its containing page. This key controls the exported page extension independently of PHP template execution.

<key>requiresPhp</key><true/>

templates

Required Dictionary

Declares the component templates currently processed by Foundry.

html
Required primary HTML template filename. Processed once per component instance.
files
Optional array of template dictionaries. CSS and JavaScript accept instance (default), page, or site scope. JavaScript also accepts optional Boolean closure, defaulting to true. Instance closures receive the native component element; page/site closures receive page as document. Additional HTML requires page scope and a placement of headStart, headEnd, bodyStart, or bodyEnd.
editorCSS
Optional instance-scoped, canvas-only CSS template excluded from production export.
<key>templates</key>
<dict>
    <key>html</key><string>component.html</string>
    <key>files</key>
    <array>
        <dict>
            <key>path</key><string>component.css</string>
            <key>scope</key><string>instance</string>
        </dict>
        <dict>
            <key>path</key><string>component.js</string>
            <key>scope</key><string>instance</string>
        </dict>
    </array>
    <key>editorCSS</key><string>editor.css</string>
</dict>
Partly proposed. PHP templates are accepted, included in exported PHP pages and executed by Foundry’s bundled local-preview runtime. Sass/SCSS compilation remains proposed.
<key>requiresPhp</key><true/>
<key>files</key>
<array>
        <dict>
            <key>path</key><string>styles/component.scss</string>
            <key>scope</key><string>instance</string>
        </dict>
        <dict>
            <key>path</key><string>server/component.php</string>
            <key>scope</key><string>site</string>
        </dict>
</array>

PHP source is macro-processed and placed before the page doctype. Instance scope is emitted for every component instance; page and site scope are deduplicated by component bundle identifier on each exported page. PHP templates require requiresPhp. Foundry’s bundled runtime executes generated PHP pages during local preview; Sass/SCSS compilation remains proposed. See Templates.

assets

Optional String array

Static component resources copied during export.

Author controls

customItems

Optional Dictionary array

Component-specific inspector controls. Value-producing items require id, title, group, control, default, responsive. Optional toolTip adds help. A control dictionary can specify count from 2 through 4; its default is then an equal-length array and optional subtitles labels the members. Presentation-only divider and info, and virtual math and imageTransform items, require only id, group, and control. See Custom controls.

slots

Optional Dictionary array

Named child-component regions. Each slot requires id, title, accepts, and minimum; maximum is optional. See Child components.

Support and recovery

helpURL

Optional URL String

Absolute component support or documentation URL.

missingComponent

Optional Dictionary

Fallback retained when the package is unavailable. Accepts optional message and HTML preview Strings.

Minimal component Info.plist

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>type</key><string>component</string>
    <key>CFBundleIdentifier</key><string>uk.co.example.component</string>
    <key>title</key><string>Example</string>
    <key>templates</key>
    <dict>
        <key>html</key><string>component.html</string>
    </dict>
</dict>
</plist>
