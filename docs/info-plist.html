Plist reference

Info.plist

The current developer-facing keys accepted by a component .foundrypack. Paths are relative to Contents/Resources.

Identity

type

Required String

component, theme, or collection. The remaining component-specific keys on this page apply when the type is component.

CFBundleIdentifier

Required String

Globally unique, stable reverse-domain identity, for example uk.co.example.callout. Changing it creates a different component.

title

Required String

Human-readable library and inspector name.

description

Optional String

Short library description.

author

Optional String

Developer, company or publisher.

version

Optional String

Human-readable component version such as 1.0 or 2.1.3.

group

Optional StringDefault: Other

Library group: Layout, Content, Media, Navigation, Forms, Interactive, or Other.

tags

Optional String array

Additional component-library search terms.

Rendering

templates

Required Dictionary

Declares the component templates currently processed by Foundry.

html
Required primary HTML template filename. Processed once per component instance.
files
Optional array of template dictionaries. CSS and JavaScript accept instance (default), page, or site scope. Additional HTML requires page scope and a placement of headStart, headEnd, bodyStart, or bodyEnd.
editorCSS
Optional instance-scoped, canvas-only CSS template excluded from production export.
<key>templates</key>
<dict>
    <key>html</key><string>component.html</string>
    <key>files</key>
    <array>
        <dict>
            <key>path</key><string>component.css</string>
            <key>scope</key><string>instance</string>
        </dict>
        <dict>
            <key>path</key><string>component.js</string>
            <key>scope</key><string>instance</string>
        </dict>
    </array>
    <key>editorCSS</key><string>editor.css</string>
</dict>
Proposed formats. Sass/SCSS and PHP are designed but not yet accepted by the app.
<key>files</key>
<array>
        <dict>
            <key>path</key><string>styles/component.scss</string>
            <key>scope</key><string>instance</string>
        </dict>
        <dict>
            <key>path</key><string>server/component.php</string>
            <key>scope</key><string>site</string>
        </dict>
</array>

When implemented, page and site entries will be deduplicated by component bundle identifier and path and will reject instance-only macros. Sass/SCSS compilation and PHP execution are also proposed. See Templates.

assets

Optional String array

Static component resources copied during export.

Author controls

customItems

Optional Dictionary array

Component-specific inspector values. Each item requires id, title, section, control, default, responsive, and inlineEditable. See Custom controls.

slots

Optional Dictionary array

Named child-component regions. Each slot requires id, title, accepts, and minimum; maximum is optional. See Child components.

Support and recovery

helpURL

Optional URL String

Absolute component support or documentation URL.

missingComponent

Optional Dictionary

Fallback retained when the package is unavailable. Accepts optional message and HTML preview Strings.

Minimal component Info.plist

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN"
  "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>type</key><string>component</string>
    <key>CFBundleIdentifier</key><string>uk.co.example.component</string>
    <key>title</key><string>Example</string>
    <key>templates</key>
    <dict>
        <key>html</key><string>component.html</string>
    </dict>
</dict>
</plist>
