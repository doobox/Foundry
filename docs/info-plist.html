Foundry API›Component bundles

Info.plist

Every supported property-list entry for a component .foundrypack bundle.

Identity and library

type

Type: StringRequired

Declares what the Foundry pack provides. Use component for a component bundle or theme for a theme bundle. The remaining entries documented on this page apply to component packs.

<key>type</key>
<string>component</string>

CFBundleIdentifier

Type: StringRequired

The globally unique identity of the component. Use a lowercase reverse-domain identifier such as uk.co.example.text. Foundry uses it to identify the component in documents and to generate its package-wide CSS scope. Changing this value creates a different component identity.

<key>CFBundleIdentifier</key>
<string>uk.co.example.text</string>

title

Type: StringRequired

The human-readable component name displayed in Foundry’s component library, inspector and editor chrome.

<key>title</key>
<string>Text</string>

description

Type: StringDefault: empty

A short explanation of what the component does. Foundry displays it with the component’s library information.

author

Type: StringOptional

The developer, company or publisher responsible for the component.

version

Type: StringOptional

A human-readable component version displayed by Foundry, such as 1.0 or 2.1.3. This is Foundry’s simple version entry and is not CFBundleShortVersionString.

<key>version</key>
<string>1.0</string>

group

Type: StringDefault: Other

The preset component-library group in which Foundry displays the component. Supported values are Layout, Content, Media, Navigation, Forms, Interactive and Other. Matching is case-insensitive. A missing or unsupported value resolves to Other.

<key>group</key>
<string>Content</string>

tags

Type: Array of StringsDefault: empty array

Additional terms used when searching the component library. Tags should describe purpose and common terminology rather than repeat the title.

<key>tags</key>
<array>
    <string>copy</string>
    <string>paragraph</string>
</array>

Templates and content

templates

Type: DictionaryRequired

Declares the files Foundry processes when rendering this component. Every path is relative to Contents/Resources.

html
String, required. The component’s HTML template.
css
String, optional. Component CSS included in the canvas and export, scoped to this bundle identifier.
editorCSS
String, optional. Canvas-only CSS that is not included in exported sites.
<key>templates</key>
<dict>
    <key>html</key><string>component.html</string>
    <key>css</key><string>component.css</string>
    <key>editorCSS</key><string>editor.css</string>
</dict>

assets

Type: Array of StringsDefault: empty array

Static resource files belonging to the component. Declared assets can be referenced from templates and are copied when Foundry exports the site. Each path is relative to Contents/Resources.

customItems

Type: Array of DictionariesDefault: empty array

Declares component-specific values that Foundry presents in the inspector. Every dictionary creates one stored property on each component instance.

id
String, required. Stable identifier used in stored component data and template substitutions. It must be unique within this component.
title
String, required. Human-readable label shown beside the inspector control.
section
String, required. Inspector section in which the control is displayed. Items with an identical value are grouped together.
control
Dictionary, required. Describes the inspector control. See the control dictionary entries below.
default
String, Number or Boolean, required. Initial value assigned to a newly created component. Its plist type must match the selected control.
responsive
Boolean, required. When true, Foundry stores values per breakpoint. When false, one value applies at every breakpoint.
inlineEditable
Boolean, required. Allows the value to be edited directly on the canvas when supported by the component template.
css
String, optional. CSS declaration template generated from the selected value.

control dictionary

type
String, required. One of text, textArea, number, color, select, url, image or toggle.
minimum
Number, optional. Lowest value accepted by a number control.
maximum
Number, optional. Highest value accepted by a number control.
step
Number, optional. Increment used by a number control.
unit
String, optional. CSS unit associated with a numeric value, such as px, rem or %.
options
Array of Dictionaries, optional. Choices for a select control. Each dictionary requires a String value stored by Foundry and a String title shown to the user.
<key>customItems</key>
<array>
    <dict>
        <key>id</key><string>alignment</string>
        <key>title</key><string>Alignment</string>
        <key>section</key><string>Typography</string>
        <key>control</key>
        <dict>
            <key>type</key><string>select</string>
            <key>options</key>
            <array>
                <dict><key>value</key><string>left</string><key>title</key><string>Left</string></dict>
                <dict><key>value</key><string>center</string><key>title</key><string>Centre</string></dict>
            </array>
        </dict>
        <key>default</key><string>left</string>
        <key>responsive</key><true/>
        <key>inlineEditable</key><false/>
        <key>css</key><string>text-align: {{ value }};</string>
    </dict>
</array>

themeControls

Type: Array of DictionariesDefault: empty array

Requests standard inspector controls supplied by Foundry and backed by values available in the active theme. See Theme controls for the shared dictionary entries and supported control types.

slots

Type: Array of DictionariesDefault: empty array

Declares named regions that accept child components. A component with no slots is a leaf component.

id
String, required. Stable slot identifier. It must be unique within the component and correspond to the slot used by its HTML template.
title
String, required. Human-readable name Foundry displays for the region.
accepts
Array of Strings, required. Component identifiers or supported categories that may be placed in the slot.
minimum
Integer, required. Minimum number of child components the slot requires.
maximum
Integer, optional. Maximum number of children allowed. Omit it when the slot has no upper limit.
<key>slots</key>
<array>
    <dict>
        <key>id</key><string>content</string>
        <key>title</key><string>Content</string>
        <key>accepts</key><array><string>Components</string></array>
        <key>minimum</key><integer>0</integer>
    </dict>
</array>

Runtime and recovery

runtime

Type: DictionaryOptional

Declares an optional JavaScript runtime entry point and the browser capabilities it needs. Omit this dictionary for components that require no runtime script.

entry
String, required. JavaScript file relative to Contents/Resources.
capabilities
Array of Strings, required. Explicit runtime permissions. Supported values are dom, timers, network and localStorage.
<key>runtime</key>
<dict>
    <key>entry</key><string>component.js</string>
    <key>capabilities</key>
    <array><string>dom</string><string>timers</string></array>
</dict>

helpURL

Type: String (URL)Optional

An absolute support or documentation URL associated with the component. Foundry can expose this link when the user needs help or when the component cannot be loaded.

<key>helpURL</key>
<string>https://example.com/components/text</string>

missingComponent

Type: DictionaryOptional

Controls the fallback retained in a document when the component package is unavailable.

message
String, optional. Explanation shown in place of the unavailable component.
preview
String, optional. HTML preview preserved for the missing component.
<key>missingComponent</key>
<dict>
    <key>message</key><string>Install the Text component to edit this content.</string>
    <key>preview</key><string>&lt;p&gt;Text component&lt;/p&gt;</string>
</dict>
