Editable text

Add canvas-editable plain text without declaring a custom control or accepting a Foundry-generated HTML wrapper.

With your own default

<h2>%text="A useful heading"%</h2>

The supplied text is used until the site author edits it.

With placeholder copy

<p>%text%</p>

Foundry supplies its standard placeholder paragraph as the initial value.

Use it more than once

<article id="{{ id }}" {{ component.attributes }}>
    <h2>%text="Title"%</h2>
    <p>%text%</p>
    <small>%text="Footnote"%</small>
</article>

Foundry assigns stable internal property keys in declaration order. Each primitive expands to escaped plain text. The surrounding element always belongs to the developer.

Use custom controls for named values. If text needs a meaningful template ID, responsive variants, or use outside its immediate markup position, declare it under customItems.
