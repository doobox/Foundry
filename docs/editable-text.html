Editable text

Text primitives create canvas-editable content without property declarations or generated HTML wrappers.

Text with a default

%text="Default text"%

Foundry uses the supplied string until the user edits the component.

Generated placeholder paragraph

%text%

Foundry supplies one standard Lorem ipsum paragraph as the initial content.

Multiple values

<h2>%text="Title"%</h2>
<p>%text%</p>
<small>%text="Footnote"%</small>

Primitives may be repeated and mixed. Foundry generates stable internal property keys in declaration order, so developers do not need to name them.

Each primitive expands to escaped plain text. Foundry does not add a paragraph, span or other exported wrapper; the component developer supplies the surrounding HTML.
