Font size — fontSize

Adds a theme-aware type-size picker and applies its selection to the component root.

Control type: fontSizeOutput: theme size reference

title

Type: StringDefault: Font size

The label displayed for the size picker in the component inspector.

group

Type: StringDefault: Typography

The inspector group containing the size picker.

default

Type: StringDefault: base

The theme size assigned to a newly inserted component. Portable component defaults use the standard names xs, sm, base, lg, xl, and 2xl through 9xl. An unsupported default prevents the component from loading.

responsive

Type: BooleanDefault: false

Enables independent theme-size selection at each responsive breakpoint when set to true.

Stored value and output

Foundry stores the stable size name rather than copying a literal measurement. Each custom theme size contains a rem font size and one of Tailwind’s named line heights: none, tight, snug, normal, relaxed, or loose. Foundry emits both font-size and the corresponding unitless line-height through theme variables, relative to the theme's configurable root size.

    <key>responsive</key><true/>
