Theme-aware custom control

Font size

A fontSize custom item provides a size editor. Enable themeValues to add the project’s type scale alongside custom sizes.

Example

<key>customItems</key>
<array>
    <dict>
        <key>id</key><string>textSize</string>
        <key>labels</key><string>Text size</string>
        <key>group</key><string>Typography</string>
    <key>type</key><string>fontSize</string>
            <key>themeValues</key><true/>
        <key>default</key><string>base</string>
        <key>responsive</key><true/>
    </dict>
</array>
#{{ id }} { font-size: {{ control.textSize }}; }

Theme choices

The portable scale names are xs, sm, base, lg, xl, and 2xl through 9xl. The project theme resolves each name to its configured measurement. Custom values remain available because this is still a custom control.

One value, one target. The developer decides where the size is applied through the template; Foundry does not force typography onto the component root.
