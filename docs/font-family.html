Font family — fontFamily

Adds a theme-aware font-family picker and applies its selection to the component root.

Control type: fontFamilyOutput: theme font reference

title

Type: StringDefault: Font family

The label displayed for the font picker in the component inspector.

group

Type: StringDefault: Typography

The inspector group containing the font picker.

default

Type: StringDefault: body

The theme font role assigned to a newly inserted component.

Supported portable values:

body
The active theme’s body font.
heading
The active theme’s heading font.
monospaced
The active theme’s monospaced font.

Custom-font UUIDs belong to a particular theme and cannot be used as portable component defaults. An unsupported default prevents the component from loading.

responsive

Type: BooleanDefault: false

Enables independent font-family selection at each responsive breakpoint when set to true.

Inspector options

The user can select Body, Heading, Monospaced, or any custom font defined by the active theme. Foundry displays both the role/name and its current family, such as Heading — Playfair Display.

Stored value and output

Foundry stores a stable theme-font reference rather than copying the literal family name. It emits instance-specific font-family CSS for the selected component. If the theme changes the referenced family, every component using that reference updates automatically.
