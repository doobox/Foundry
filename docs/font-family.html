Smart control

Font family

A fontFamily custom item lets the author choose a family. Enable themeValues to include portable theme roles and theme-defined fonts alongside custom choices.

Example

<key>customItems</key>
<array>
    <dict>
        <key>id</key><string>typeface</string>
        <key>title</key><string>Typeface</string>
        <key>group</key><string>Typography</string>
        <key>control</key>
        <dict>
            <key>type</key><string>fontFamily</string>
            <key>themeValues</key><true/>
        </dict>
        <key>default</key><string>body</string>
        <key>responsive</key><true/>
    </dict>
</array>
#{{ id }} { font-family: {{ control.typeface }}; }

Theme choices

body
The active theme’s body family.
heading
The active theme’s heading family.
monospaced
The active theme’s monospaced family.
Theme-defined fonts
Any additional font made available by the project theme.

The stored semantic selection stays live when the theme changes; the template receives the resolved CSS value.
