Component quick start

Create the smallest useful Foundry component.

1. Create the bundle

MyText.foundrypack/
└── Contents/
    ├── Info.plist
    └── Resources/
        ├── component.html
        └── component.css

2. Add Info.plist

<key>type</key>
<string>component</string>
<key>CFBundleIdentifier</key>
<string>uk.co.example.my-text</string>
<key>title</key>
<string>My Text</string>
<key>templates</key>
<dict>
    <key>html</key><string>component.html</string>
    <key>css</key><string>component.css</string>
</dict>

3. Add editable content

<p class="my-text{{ component.class }}" {{ component.attributes }}>
    %text="Write something"%
</p>

Foundry infers the content property and displays its editor in the inspector.
