Inspector API

Custom controls

Declare inspector controls in customItems, then consume their values from HTML, CSS, JavaScript and PHP templates. Choose a control below for its complete declaration, options, value type and template example.

Declare a property

Every value-producing item has a stable id, author-facing title, inspector group, a control dictionary, a matching default, and explicit responsive and inline-editing behaviour.

<dict>
    <key>id</key><string>heading</string>
    <key>title</key><string>Heading</string>
    <key>group</key><string>Content</string>
    <key>control</key>
    <dict><key>type</key><string>text</string></dict>
    <key>default</key><string>Welcome</string>
    <key>responsive</key><false/>
    <key>inlineEditable</key><false/>
</dict>

Read the value with {{ control.heading }} or {{ property.heading }}.

Control types

text

Single-line text.

textArea

Multi-line text.

url

A URL string.

link

A structured internal or external link.

number

Numeric input with bounds and units.

slider

Numeric slider with optional ticks.

date

An ISO-8601 date.

color

Custom and theme-aware colour.

select

A choice from declared options.

toggle

A Boolean switch.

details

A compact Boolean details button.

button

A persistent action button.

image

A project asset picker.

imageTransform

A derived transformed image URL.

math

A derived numeric value.

textAlignment

Logical CSS alignment.

fontFamily

Theme-aware font family.

fontSize

Theme-aware font size.

info

Presentation-only help text.

divider

A presentation-only separator.
