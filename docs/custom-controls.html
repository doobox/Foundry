Inspector API

Request the values you need

Each dictionary in customItems adds a control to Foundry’s inspector. Its id becomes available to every declared template as {{ control.id }}.

Property shape

id
Required stable developer-facing identifier.
title
Required label shown to the site author.
group
Required inspector group. Items with the same name appear together in one disclosure group.
control
Required dictionary describing the editor.
default
Required String, Number or Boolean matching the control.
responsive
Required Boolean. Enables breakpoint overrides.
inlineEditable
Required Boolean. Enables direct canvas editing where supported.

Text control

A text control creates a standard single-line text field in the inspector. The declaration below adds a field labelled Heading to the Content group.

<key>customItems</key>
<array>
    <dict>
        <key>id</key><string>heading</string>
        <key>title</key><string>Heading</string>
        <key>group</key><string>Content</string>
        <key>control</key>
        <dict>
            <key>type</key><string>text</string>
        </dict>
        <key>default</key><string>PHP is alive</string>
        <key>responsive</key><false/>
        <key>inlineEditable</key><false/>
    </dict>
</array>

Use its value in any declared template with {{ control.heading }}. With responsive set to false, the value is shared by every breakpoint. With inlineEditable set to false, it is edited only in the inspector; setting it to true also permits direct canvas editing where the rendered text can be associated with this property.

This is different from %text%. The %text% template macro creates a dedicated inline-editable text area automatically. Use a declared text control when you want a named inspector value such as a heading, label or short message.

Divider control

A divider deliberately separates controls inside a disclosure group. It is presentation-only: it has no editable value and cannot be referenced by a template.

<dict>
    <key>id</key><string>contentDivider</string>
    <key>group</key><string>Content</string>
    <key>control</key>
    <dict>
        <key>type</key><string>divider</string>
    </dict>
</dict>

The id must still be unique because it identifies the item and preserves its declared position. Do not add title, default, responsive or inlineEditable; those keys describe value-producing controls and do not apply to a divider.

Control types

text
Single-line String.
textArea
Multi-line String.
number
Number with optional minimum, maximum, step and unit.
color
Custom and theme colours, with optional colour math and opacity.
textAlignment
Smart segmented control producing logical CSS alignment values.
select
A choice from options, each containing value and title.
url
A URL String.
image
An asset selected from the project.
toggle
A Boolean switch.
divider
A deliberate visual separator with no template value.

Example

<key>customItems</key>
<array>
    <dict>
        <key>id</key><string>alignment</string>
        <key>title</key><string>Alignment</string>
        <key>group</key><string>Layout</string>
        <key>control</key>
        <dict>
            <key>type</key><string>select</string>
            <key>options</key>
            <array>
                <dict><key>value</key><string>left</string><key>title</key><string>Left</string></dict>
                <dict><key>value</key><string>center</string><key>title</key><string>Centre</string></dict>
                <dict><key>value</key><string>right</string><key>title</key><string>Right</string></dict>
            </array>
        </dict>
        <key>default</key><string>left</string>
        <key>responsive</key><true/>
        <key>inlineEditable</key><false/>
    </dict>
</array>
#{{ id }} { text-align: {{ control.alignment }}; }
CSS stays in CSS. Controls describe values; templates decide how those values affect the component.
