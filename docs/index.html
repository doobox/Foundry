Component API

Your markup. Your CSS. Foundry does the wiring.

Build portable components from ordinary files. Declare inspector controls in Info.plist, then place their values exactly where your HTML and CSS need them.

Build your first componentLearn the template API

The model

1. Package files

Put a plist, icon, templates and assets inside a standard .foundrypack.

2. Request controls

Describe the values an author can edit, including responsive and theme-aware controls.

3. Consume values

Use {{ id }} and {{ control.name }} in developer-owned templates.

Small on purpose. Foundry substitutes values and renders slots; it does not invent your component structure or provide a general-purpose template language.

Core syntax

{{ id }}
Stable, CSS-safe ID for this component instance.
{{ control.padding }}
The resolved value of a declared control.
{% slot id="content" %}
Where child components are rendered.
%text="Default"%
Text the site author can edit directly.
