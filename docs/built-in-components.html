Product roadmap

Built-in components

The essential component collection Foundry should provide so an author can build a complete website without third-party add-ons. This is a working reference: implementing the components will also help expose missing API capabilities and controls.

Layout reference: Foundry remains framework-free, but its layout primitives follow the proven separation used by Bootstrap: a full-width page region contains a width-constrained container, which in turn contains a row, stack or grid. See Bootstrap's Containers and Grid documentation.

Core building blocks

Layout

Section Available
A full-width semantic page region with background, responsive vertical spacing and minimum-height controls. It deliberately does not constrain content width.
Container Available
Centres and constrains content and provides its horizontal gutters. Place one inside a Section for the standard page-building pattern.
Stack
A responsive vertical or horizontal flex layout.
Grid
Responsive columns with configurable gaps and alignment.
Spacer
Intentional responsive space between elements.
Divider
A horizontal or vertical visual separator.

Text

Heading
Editable text with h1–h6 semantics independent of its visual size.
Paragraph
Editable body copy with typography, alignment and colour controls.
Rich Text
Headings, paragraphs, lists, emphasis and links in one editable region.
List
Ordered or unordered repeatable items.
Text Link
An inline link to a site page, URL, email address or telephone number.
Button
A prominent styled link or action.
Blockquote
A semantic quotation with an optional citation.
Code / Preformatted Text
Semantic inline or block code with preserved formatting.

Media

Image
An accessible responsive image with sizing, fit and presentation controls.
Icon
An icon selected from Foundry’s built-in icon library.
Video
Hosted or local video with playback and accessibility options.
Audio
Audio playback with appropriate metadata and controls.
Embed
An iframe or trusted third-party embed.
Gallery
A repeatable collection of images with responsive layout controls.

Site structure and navigation

Site Logo
A site identity image linked to the homepage.
Navigation Menu
Navigation generated from the project’s page hierarchy.
Breadcrumbs
The current page’s position in the site hierarchy.
Social Links
A repeatable set of labelled social destinations and icons.

Forms

Form
The semantic form container, submission destination and shared validation behavior.
Text Field
A labelled single-line text input.
Email Field
An email input with appropriate browser semantics.
Telephone Field
A telephone input with appropriate browser semantics.
Number Field
A numeric input with optional range and step rules.
Text Area
A labelled multiline text input.
Select Menu
A labelled choice from a defined set of options.
Checkbox
A single Boolean choice.
Radio Group
One choice from a visible group of options.
Submit Button
A form-aware submission action.
Form Status / Validation Message
Accessible success, failure and validation feedback.

Utility

HTML
Trusted custom HTML, CSS and JavaScript for advanced authors.
Anchor / Page Position
A named destination for links within a page.
Alert / Callout
A visually distinct informational, warning or error message.
Details / Accordion
Expandable content built on appropriate disclosure semantics.

Expected interactive components

These are not required to assemble a basic page, but users will reasonably expect them in a complete built-in collection.

  • Tabs
  • Modal / Dialog
  • Slideshow
  • Responsive Picture
  • Navigation Dropdown
  • Mobile Menu
  • Search Field
  • Pagination
  • Progress Indicator
  • Table

Ready-made composite components

These should be assembled from the core building blocks wherever possible, providing useful starting points without introducing a second layout system.

  • Site Header
  • Hero Section
  • Feature Grid
  • Card
  • Image and Text Section
  • Call to Action
  • Pricing Table
  • Testimonials
  • FAQ
  • Contact Form
  • Site Footer

Recommended build order

  1. Section
  2. Container
  3. Heading
  4. Button
  5. Stack
  6. Grid
  7. Divider
  8. List
  9. Icon
  10. Video
  11. Navigation Menu
  12. Form and its fields
  13. Rich Text
Why this order? It introduces editable content, semantic elements, link controls, responsive layout, child slots, repeated data, libraries, page-tree access and forms progressively, making API gaps easier to identify and solve.
