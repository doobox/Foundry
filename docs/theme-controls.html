Theme controls

The shared dictionary entries accepted by every Foundry-provided theme control.

type

Type: StringRequired

Identifies the control Foundry should provide. Supported values are fontFamily and fontSize. Unknown values prevent the component plist from loading.

title

Type: StringControl-specific default

The label displayed beside the control in the inspector. Omit it to use the standard title defined by Foundry for that control.

group

Type: StringControl-specific default

The inspector group containing the control. Controls with the same group name are displayed together.

default

Type: Control-specificControl-specific default

The value assigned when a new component instance is inserted. Supported values and the fallback are documented by each control type.

responsive

Type: BooleanDefault: false

When true, the inspector permits different values at supported breakpoints. Values inherit from narrower breakpoints until the user creates an override, and an override can be reset to restore inheritance.

Example

<key>themeControls</key>
<array>
    <dict>
        <key>type</key><string>fontFamily</string>
        <key>title</key><string>Typeface</string>
        <key>group</key><string>Typography</string>
        <key>default</key><string>heading</string>
        <key>responsive</key><true/>
    </dict>
</array>
