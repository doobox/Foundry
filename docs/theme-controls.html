Custom controls

Theme-aware controls

color and fontSize can combine project-theme values with custom values. fontFamily exclusively presents fonts configured in the Theme Editor. They remain ordinary customItems controls and use the same property declaration and template macros as every other custom control.

One custom-control model

Theme awareness does not introduce another plist collection or API category. Set themeValues on a supported custom control, give the property an ID, and consume its resolved value through the usual template macro.

<dict>
    <key>id</key><string>alignment</string>
    <key>labels</key><string>Alignment</string>
    <key>group</key><string>Typography</string>
    <key>type</key><string>textAlignment</string>
    <key>default</key><string>start</string>
    <key>responsive</key><true/>
</dict>
#{{ id }} {
    text-align: {{ control.alignment }};
}

For textAlignment, Foundry provides a segmented control with the correct alignment symbols, portable choices and validated CSS output. The developer does not need to rebuild that option list for every component.

Theme-aware and specialised behaviour

Theme-aware values
color and fontSize use themeValues to add compatible project-theme choices. fontFamily is always theme-aware.
Specialised UI
textAlignment is a specialised custom control with segmented symbols and known CSS semantics, but it does not read theme values.
Stable output
Each control resolves to its documented CSS-safe value through {{ control.<id> }}.
Responsive support
These custom controls can inherit and override values at Foundry breakpoints.

Good candidates

Typography
Font weight, line height, letter spacing, text decoration, text transform and whitespace.
Layout
Display, flex/grid alignment, gap, sizing, overflow and aspect ratio.
Appearance
Border style, corner radius, shadow, opacity and blend mode.
Media
Object fit, object position, loading behaviour and aspect ratio.
Links and behaviour
Link target, relationship, cursor and visibility.
Accessibility
Landmark role, labels and appropriate ARIA choices where a component genuinely needs them.
