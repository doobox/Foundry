Shared capability

Control arrays

Display two, three or four controls together in one inspector row while retaining normal bindings, persistence, responsive overrides and undo behaviour.

Declaration

Add count to the control dictionary. The default array must contain exactly the same number of values. Optional subtitles label the individual controls.

<dict>
    <key>id</key><string>palette</string>
    <key>title</key><string>Palette</string>
    <key>group</key><string>Appearance</string>
    <key>control</key>
    <dict>
        <key>type</key><string>color</string>
        <key>count</key><integer>4</integer>
    </dict>
    <key>subtitles</key>
    <array>
        <string>Primary</string><string>Secondary</string>
        <string>Accent</string><string>Surface</string>
    </array>
    <key>default</key>
    <array>
        <string>#3366CC</string><string>#8A55D7</string>
        <string>#2DA44E</string><string>#F6F8FA</string>
    </array>
    <key>responsive</key><true/>
</dict>

Template values

Read members by zero-based index.

color: {{ control.palette[0] }};
background: {{ control.palette[3] }};
Counts are validated. count must be from 2 through 4, and subtitles cannot outnumber the controls.
