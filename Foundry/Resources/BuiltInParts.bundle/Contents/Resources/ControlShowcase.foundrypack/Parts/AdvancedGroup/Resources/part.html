Classes and attributes at work

The part's CSS can key off whatever the author adds to the root. Add the class fx-accent or fx-outline, or the attribute data-theme with the value dark, and this box restyles.

Custom CSS

Paste .fx-target { background: gold; } into the CSS field: it lands inside this instance's selector, so only these boxes change. :hover { outline: 2px solid red; } attaches to the root itself.
