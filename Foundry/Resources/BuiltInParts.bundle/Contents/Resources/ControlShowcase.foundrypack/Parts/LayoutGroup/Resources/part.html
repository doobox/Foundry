Layout

The full group. The dashed stage is positioned, so Absolute offsets are measured from it; the box has more text than fits, so Overflow is visible too.

Layout box This box has a fixed height and more text than fits inside it, so choosing Hidden, Scroll or Auto for Overflow changes what you see. Hidden removes it from the flow; Visibility keeps its space.
