Framework Border

Qualified fields only: width is four CSS lengths in top, right, bottom, left order and style is a keyword. Colour is a separate control.

Widths

The default form. defaults.base.width is one token for all four edges. Each edge is also available alone, with its numeric amount under width.values and unit under width.units.
