Framework Margin

Four edges from the framework's spacing scale, plus auto and negative lengths. Printed directly it is the CSS shorthand.

Shared token

defaults.base as one token gives every edge the same var(--foundry-space-…) reference and starts both pairs linked. The striped frame shows the margin.

Per edge with auto

defaults.base as a four-edge dictionary: a token, none, a custom { value, unit } and auto. An auto edge has no numeric amount, so values.left prints empty and units.left is an empty string; check the CSS edge field before calculating. subtitle sits beneath the editor.
