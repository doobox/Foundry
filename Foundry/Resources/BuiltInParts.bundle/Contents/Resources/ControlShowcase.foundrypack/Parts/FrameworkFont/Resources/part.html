Control · frameworkFont

Framework Font

One structured value. Read its fields — family, and weight, style, size when enabled — never the whole object.

Family

The default form shows only the family row. defaults.base as a role string (body, heading, monospaced) is shorthand for a dictionary with family.

The quick brown fox jumps over the lazy dog.

control.bodyFont.family
{{ control.bodyFont.family }}

Weight and style

showsWeight and showsStyle add rows and fields. defaults.base.weight and defaults.base.style are accepted only when their row is enabled.

Size

showsSize adds the framework size row. defaults.base.size is a predefined size ID; the value is a CSS variable with its paired size.lineHeight.

Caption text set with the framework's size and leading. Wrap it over two lines to see the line height take effect on the canvas.

Fixed family

"showsFamily": false hides the family row and fixes it to the default, which is still returned. Here only Weight is editable.

let weight = {{ control.codeFont.weight }}

Responsive

"responsive": true lets each exposed row override independently per breakpoint. base is the phone value; the medium entry starts pinned. Resize the canvas to see it switch.
