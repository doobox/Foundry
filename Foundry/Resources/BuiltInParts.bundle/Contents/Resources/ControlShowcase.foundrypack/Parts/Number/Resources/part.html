Number

A number typed or stepped in a field. Templates receive a locale-independent numeric String, never the unit.

Bounds and units

minimum, maximum and step bound the field; units is an Inspector-only label. Add the unit yourself in the template.

Responsive

"responsive": true keeps a number per breakpoint. Because the control has a finite maximum, a loop control.columns block can repeat markup that many times.

Count

"count": 2 stores two numbers in one array, read by zero-based index. units and subtitle become arrays with one entry per field.
