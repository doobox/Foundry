Framework Color

A palette and shade pair that resolves to a CSS colour for the appearance being edited, with every number qualified as light or dark.

Palette

defaults.base.palette names a framework role. The value is a complete CSS colour; contrastColor adapts with it, and the light fields are fixed numbers for that appearance.
